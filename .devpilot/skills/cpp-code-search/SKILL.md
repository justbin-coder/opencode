# C++ 需求-代码检索规范

## 触发场景

当用户：
- 用自然语言询问"在 XXX 项目里找 YYY 的代码/实现/定义在哪里"
- 询问"哪些代码/类/函数实现了某功能"
- 要求定位与某个概念（如"矩阵乘法"、"SVD 分解"）相关的源码
- 输入一张需求卡片（含 id、description 字段）

## 工作流程

1. **提取需求字段**：从用户输入中识别 `id`、`description`、`acceptance_criteria`
2. **调用检索工具**：使用 `cpp_code_search` 工具，传入完整需求卡片 JSON
3. **解读结果**：基于返回的文件路径、类名、函数名，结合关联度分数（High/Medium/Low）给出分析

## 输出规范

返回结果时，必须包含：
- Top-5 代码单元的**文件路径 + 类名 + 函数名**
- 每条结果的**关联度分数**和**等级标签**
- 对 High 等级结果的**简要分析**（为什么与需求相关）

## 注意事项

- 如果工具返回"索引未构建"错误，告知用户在 devpilot TUI 中输入：`/index <代码库路径>`
- 如果 top-5 中无 High 等级结果，说明当前需求描述可能过于抽象，建议用户补充技术关键词
- 不要在未调用工具的情况下，直接猜测代码位置
