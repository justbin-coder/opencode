### Task 11: cpp-test-validator.ts

**状态:** ✅ 完成

**交付物:** `.opencode/tools/cpp-test-validator.ts` (696 行)

**核心功能:**

```
1. CppTestValidator 类 (主验证引擎)
   ├─ 构造函数: 文件加载和初始化
   ├─ validate(): 执行完整验证流程
   └─ 私有方法: 8 个具体检查

2. 验证检查项 (8 个主要分类)
   ├─ E001/E002: 空断言 (没有断言或空断言)
   ├─ W001/W002: 场景覆盖 (无法识别/缺少某类场景)
   ├─ W003: 中文注释 (缺少场景标记)
   ├─ W004: 断言清晰度 (幻数检测)
   ├─ W005/W006: Mock 规范 (EXPECT_CALL / Times)
   ├─ W007: 命名规范 (Method_Scenario 格式)
   └─ W008: 生命周期 (SetUp/TearDown)

3. 输出格式
   ├─ 测试统计: 数量, 行数
   ├─ 场景覆盖: 分布 (正常/边界/异常/未知)
   ├─ 质量评分: 0-100 分 (错误 -5, 警告 -2)
   └─ 详细问题: 位置, 类型, 建议修复

4. 命令行接口
   - 单文件验证
   - 目录批量验证
   - --json 输出格式
   - 汇总统计 (文件数, 测试数, 问题数, 平均分)

5. 代码质量指标
   ├─ 类型系统: 4 个 interface
   ├─ 函数复杂度: 各函数 ≤30 行
   ├─ 错误处理: try-catch 包装
   └─ 可测试性: 分离 validation 和 reporting
```

**验证规则详解:**

| 检查项 | 代码 | 触发条件 | 处理 |
|-------|------|---------|------|
| 空断言 | E001 | 测试无 EXPECT_* | 错误 |
| 空参数 | E002 | `EXPECT_EQ()` 无参 | 错误 |
| 未知场景 | W001 | 名称无 Boundary/Exception | 警告 |
| 场景缺失 | W002 | 正常/边界/异常不全 | 警告 |
| 注释缺失 | W003 | 无 `[场景标记]` | 警告 |
| 幻数 | W004 | 断言有硬编码数值 | 警告 |
| Mock 不全 | W005/W006 | Mock 无 EXPECT_CALL/Times | 警告 |
| 命名差 | W007 | 非 `Method_Scenario` 格式 | 警告 |
| 无生命周期 | W008 | 无 SetUp/TearDown | 警告 |

**质量指标:**
- 检查覆盖: 9 个错误/警告类别
- 评分算法: 基于错误 (-5) 和警告 (-2) 扣分
- 输出格式: JSON + 人类可读的格式报告
- 实用性: 高 (每个问题都有具体建议)
