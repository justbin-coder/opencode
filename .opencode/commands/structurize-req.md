---
description: 将自然语言需求整理为结构化需求卡片
---

使用 @.opencode/skills/req-structuring/SKILL.md 作为唯一规范来源，处理下面的请求参数：

`$ARGUMENTS`

执行规则：

1. 先解析参数。
2. 如果包含 `--file <path>`，读取该文件并提取需求文本。
3. 如果包含 `--batch <n>`，按批次处理，但最终回复中仍按需求逐条输出。
4. 如果包含 `--output <dir>`，将每条需求卡片保存到该目录；未指定时默认写入 `.opencode/requirements/`。
5. 其余文本视为单条需求输入。

输出规则：

- 严格遵循 skill 中的字段约束、编号规则、优先级规则、Mermaid 时序图要求和验收标准要求。
- 每条需求先生成结构化 JSON，再渲染为 Markdown 卡片。
- 默认状态为 `草稿`。
- 如果输入信息不足，补齐最合理的最小必要假设，不要先反问用户。
- 如果需要写文件，确保目录存在，并为每条需求分别写入 `REQ-YYYY-MM-NNN.md`。

最终回复规则：

- 单条需求时，先返回完整 Markdown 卡片，再说明写入路径。
- 多条需求时，先给出简短汇总，再逐条给出 Markdown 卡片和对应写入路径。
- 不要输出实现说明或教程，只执行需求结构化任务本身。
